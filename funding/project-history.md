# Public project history

**Status:** research snapshot, checked October 17, 2026 (America/New_York). This supports the [funding plan](README.md); it is not an eligibility determination, audit, or record of funds held.

## Scope and counting method

Read-only GitHub API review of all nine public OogaBoogaX repositories, completed at approximately 22:37 EDT on October 17, 2026. Repository creation and release dates below use GitHub's UTC dates. GitHub creation dates are repository dates, not proof that work began then. No live payment service was contacted and no payment was made.

The [organization repository API](https://api.github.com/orgs/OogaBoogaX/repos?type=public&per_page=100) supplied creation dates, descriptions and license detection. For every repository, all pages of `contributors?per_page=100&anon=false` and `releases?per_page=100` were read, along with the recursive default-branch tree and documentation. The counts are GitHub-attributed **accounts**, not an independently verified number of people or copyright owners; anonymous/unlinked identities are omitted. GitHub notes that its [contributor endpoint is cached](https://docs.github.com/en/rest/repos/repos#list-repository-contributors), so totals can lag.

“Apparent human” excludes GitHub `Bot` accounts and the `claude` and `codex` AI attribution aliases. Those aliases are explicitly identified in the project's [contributor policy documentation](https://github.com/OogaBoogaX/oogaboogaland/blob/63a1715479b6c1e80b7f113901a745681cbc17a8/docs/contributor-onboarding.md). Both aliases have API type `User`, so filtering on `type` alone would overcount humans. Other automation using ordinary accounts and multiple accounts belonging to one person cannot be ruled out. Human contributors using AI tools remain human contributors.

## External merged-PR contributor check

The requested rolling twelve-month window is **October 17, 2025, 22:37 EDT through October 17, 2026, 22:37 EDT**. Both repositories were created within that window. Every merged PR returned fell inside it, including UTC October 18 merges that were still October 17 in New York.

Method: paginate GitHub GraphQL `repository.pullRequests(states: MERGED, first: 100, after: cursor)` until `hasNextPage` is false; read `number`, `url`, `mergedAt`, `author.login`, `author.__typename`, `authorAssociation` and `mergedBy`. Deduplicate authors by login, exclude `Bot` actors and known AI aliases, then exclude anyone marked `MEMBER` or `OWNER` anywhere in the review and any independently confirmed maintainer. Cross-check the other reviewed repository and public CODEOWNERS for known maintainers. Flag `COLLABORATOR` association and observed merge authority for private role confirmation: neither alone proves a contributor is a maintainer or organization member. This removes known insiders without assuming that every committer is external.

| Repository | Merged PRs read | Distinct PR authors | Excluded bot authors | Excluded member authors | Collaborator role unresolved | Possible external accounts |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| EntropyLab | 663 | 32 | 2 | 12 | 1 | **At most 18** |
| Ooga Booga Land | 168 | 17 | 2 | 10 | 0 | **At most 5** |

Arithmetic: **32 − 2 − 12 = 18**; **17 − 2 − 10 = 5**. EntropyLab collaborator `csuwildcat` self-merged [PR #174](https://github.com/OogaBoogaX/entropylab/pull/174), demonstrating merge authority, but a current maintainer role was not independently established. Retain that account in the upper bound pending private confirmation; if confirmed as a maintainer, **18 − 1 = 17**. All other observed human merge actors were already excluded as members. The `claude` and `codex` accounts were not PR authors in these results. PR totals also reconcile: EntropyLab 461 human-authored + 202 bot-authored = 663; Ooga Booga Land 165 + 3 = 168.

The [public-members endpoint](https://api.github.com/orgs/OogaBoogaX/public_members?per_page=100) returned an empty array; it does **not** prove there are no members. PR associations identify many members, but do not supply a complete membership or maintainer roster. The remaining counts are therefore **public-data upper bounds**, not certified external-human totals. The team must privately check membership, maintenance roles and account identity before making an eligibility claim. These bounds are already below the 20-external-contributor criterion listed by [Claude for Open Source](https://claude.com/contact-sales/claude-for-oss), checked October 17, 2026; they do not meet that listed route. The program also invites applications from projects outside its criteria, so this is not a rejection or a reason to fabricate eligibility.
