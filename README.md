# Banana Certified Accounting 🍌🦍

Count bananas. Keep receipts. Build in public.

“Banana Certified” is the project name, not a claim of professional accounting certification. These documents contain plans and a proposed management-reporting format; they are not audited financial statements.

This is Team Ooga Booga's home for funding plans, project budgets, proposed expense rules, and public financial updates. General-purpose open-source accounting software that anyone can use, including the team, is **planned**. No accounting application exists here yet; see the [Proposed software brief](software/README.md).

We are a worldwide group of volunteer developers. We build in public so people can follow the work, get interested, and learn how to contribute. We actively teach people who want to get involved and help them take part themselves. This is the team's description of its work, supplied October 17, 2026; linked public evidence is collected in the [project history](funding/project-history.md).

Our immediate funding goal is to cover project expenses, mainly AI development tools. Paid development may be considered later if donations or grants support it.

## Status labels

We use these words consistently, so a reader can tell a plan from a fact.

- **Estimate:** a planning figure with a stated basis. It may use historical records, but is not an actual transaction for the forecast period.
- **Actual:** a historical amount supported by records, labeled with its period and what it measures. **Actual invoiced/incurred** is distinct from **Actual paid**; an invoice alone does not prove payment. Paid amounts require payment evidence and reconciliation.
- **Draft / Proposed:** written for discussion. It has no effect until adopted.
- **Planned:** intended future work; it does not assert that software or a service exists.
- **Deferred:** deliberately set aside; reconsideration requires a new decision, and does not authorize contact or action.
- **Approved / Adopted:** decided, with the date and evidence in the [decision log](governance/decisions.md).
- **Potential:** a funding route being explored. Nothing has been promised.
- **Committed:** a written agreement, award, or pledge exists. **Received** means the money has actually arrived.
- **Not sent / Sent:** for outgoing messages. Sending requires a team decision.

## Which document wins

If two documents disagree, the authoritative source is:

- **Budget figures:** [finance/budget.md](finance/budget.md).
- **Evidence of recorded decisions:** [governance/decisions.md](governance/decisions.md). Missing evidence means approval is not established here; it does not prove no outside agreement or obligation exists.
- **Funding route status:** [funding/README.md](funding/README.md).
- **SPI facts:** SPI's own pages. The [fit check](funding/spi/fit-check.md) records what they said and when.
- **Funds held by a sponsor:** that sponsor's records.
- **Public profile wording:** [organization/profile-README.md](organization/profile-README.md). The published copy lives in `OogaBoogaX/.github`.

## How we use this repository

- Label estimates, actual transactions, proposals, and approved decisions clearly.
- Discuss changes to plans and policies in pull requests.
- Record approvals in the [decision log](governance/decisions.md), with the date and evidence.
- Publish useful summaries. Keep original invoices, tax forms, donor identities, bank and wallet details, and account credentials in restricted storage outside this public repository. The [`.gitignore`](.gitignore) helps, but it is not access control, so review every change before publishing.
